# Palindrome Checker App

A Java application to check if strings are palindromes with different use cases.

## 📁 Project Structure

```
PalindromeCheckerApp/
├── UC1/                          # Use Case 1 (Welcome Message Module)
│   └── UC1_PalindromeChecker.java
├── UC2/                          # Use Case 2 (Hardcoded Palindrome)
│   └── UC2_PalindromeChecker.java
├── src/                          # Original combined version
│   └── PalindromeCheckerApp.java
└── README.md

```

## 🎯 Use Cases

### UC1 - Welcome Message Module
**File:** `UC1/UC1_PalindromeChecker.java`

**Direct Link:** [UC1_PalindromeChecker.java](UC1/UC1_PalindromeChecker.java)

**Features:**
- Display welcome message
- Introduce the Palindrome Checker App

**How to run:**
```bash
javac UC1/UC1_PalindromeChecker.java
java -cp UC1 UC1_PalindromeChecker
```

---

### UC2 - Hardcoded Palindrome Check
**File:** `UC2/UC2_PalindromeChecker.java`

**Direct Link:** [UC2_PalindromeChecker.java](UC2/UC2_PalindromeChecker.java)

**Features:**
- Includes UC1 (Welcome Message)
- Checks 7 hardcoded palindrome strings
- Implements palindrome checking algorithm

**Test Strings:**
- ✓ racecar
- ✓ level
- ✓ madam
- ✓ noon
- ✗ hello
- ✗ world
- ✗ java

**How to run:**
```bash
javac UC2/UC2_PalindromeChecker.java
java -cp UC2 UC2_PalindromeChecker
```
